# BGMM
BGMM (BackGround Music Morpher) tries to emulate the cool fade in , fade out and pause effect done by opera gx for background music to your music app of choice. Very simple script which shouldnt take a lot (if any) resources. If it does take more than you want , you can edit the 3 big values at the start and labelled for edition.

use it in hyprland config as an exec_once for maximum slickness.

# Requirements
Linux (duh its a .sh file)
playerctl for actually controlling the player
jq for helping in writing config and storing values in JSON files.
